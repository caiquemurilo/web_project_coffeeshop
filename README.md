# Coffee Shop Website ☕

## Project Description

This project consists of a landing page for a fictional coffee shop, developed as part of the **TripleTen Web Development Bootcamp**. The main objective was to create a semantic, accessible, and visually structured web page using fundamental web technologies.

The project showcases a layout designed to present the brand, products, and includes a reservation/contact form. It serves as a practical application of layout construction and code organization principles.

## Technologies and Techniques Used

- **HTML5:** Semantic structure for better accessibility and SEO.
- **CSS3:** Styling and layout design.
- **BEM Methodology (Block Element Modifier):** Used to ensure code maintainability and scalability.
- **Flat Directory Structure:** File organization strategy to keep the CSS architecture clean and easy to navigate.

## Future Improvements

While working on this project, I identified key areas to enhance the user experience and functionality in future iterations:

- **Mobile Responsiveness:** Implement media queries to ensure the layout adapts seamlessly to smartphones and tablets, providing a fully responsive experience.
- **Backend Integration:** Develop or connect a backend service to process the data from the reservation form, allowing for real-time functional submissions.
